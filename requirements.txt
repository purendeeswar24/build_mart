# There is nothing to pip-install.
#
# Equivalent of "python -m venv && pip install -r requirements.txt":
#   make install
#   or:  .\make.ps1 install
#
# Then:
#   make up        start shop + API + admin
#   make test      unit tests
#   make test-dry  live hire dry-run (API must be running)
#   make down      stop the stack
